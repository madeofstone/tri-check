# Tri-Tracker

Agent context for this repo lives in [AGENTS.md](AGENTS.md) and
[.agents/](.agents/). Read [.agents/architecture.md](.agents/architecture.md)
before changing anything — the AAC and Databricks APIs behave in ways their
field names do not suggest.

- [Architecture](.agents/architecture.md) — what the app does, where code lives
- [Conventions](.agents/conventions.md) — how to change things safely
- [Decisions](.agents/decisions.md) — why the design is as it is
- [Handoff](.agents/handoff.md) — current state and open questions

Start a session by checking the branch and reading the architecture and handoff
docs. End it by updating the handoff, logging decisions, and committing with a
conventional prefix. Do not push unless asked.
